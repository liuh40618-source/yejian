# Security Policy

## Status

页见 (`0.1.0`) is a **private**, self-hosted fork of Reactive Resume `v6.0.10`.
There is no public release channel, package registry entry, or hosted service yet.
The repository has no remote configured and has not been published.

Because this fork intentionally diverges from upstream (locales narrowed, template IDs
renamed, upstream templates removed), **upstream security updates are not automatically
merged**. Relevant upstream advisories have to be evaluated and ported manually.
See `UPSTREAM-DIFF.md` for the exact baseline and the diverged areas.

## Reporting a Vulnerability

If you find a security issue, please report it **privately** to the repository owner
rather than opening an issue. Include:

- A description of the vulnerability and its impact.
- Steps to reproduce or a proof of concept.
- Affected versions, configuration, or deployment details.
- Any relevant logs, screenshots, or links.

If the issue originates in upstream code rather than in this fork's modifications,
please also report it to the upstream project:
<https://github.com/reactive-resume/reactive-resume/security>

## Before a public release

This policy must be revisited before publication: a public contact address, a
coordinated disclosure timeline, and localized privacy / terms pages are still
missing. The Mobile app's legal links currently still point to the upstream
documentation site.
